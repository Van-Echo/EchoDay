# EchoDay bundled fonts

- `NotoSansSC-VF.ttf` is Noto Sans SC from the official Noto CJK project. It is bundled unchanged and used for the application UI.
- `EchoDayMonthKai.ttf` is a renamed subset of LXGW WenKai Regular containing only the Chinese numerals required by calendar month watermarks.
- Both upstream fonts are licensed under the SIL Open Font License 1.1. The complete license texts are stored beside the font files.

Upstream projects:

- https://github.com/notofonts/noto-cjk
- https://github.com/lxgw/LxgwWenKai

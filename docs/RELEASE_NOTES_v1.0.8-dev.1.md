# EchoDay V1.0.8-dev.1 本地验收版

此版本仅供本地手动检查，尚未发布到 GitHub。

## 新功能

- 双端导航新增“未来TODO”，用于暂未安排日期的想法和任务，复用当日 TODO 的编辑、完成、放弃、删除、筛选、排序与标签分类显示。
- PC 日历在碎碎念下方循环展示未来 TODO 中的未完成条目，每 4 秒滚动到下一条；没有待办时自动收起。点击滚动条可进入未来 TODO，右键条目可安排到今天。Android 不显示滚动栏。
- 未来 TODO 的右键菜单新增“转移到当日TODO”，转移到操作当天；也可通过原有“移动到日期”安排到指定日期。Android 使用长按或“⋮”操作菜单。
- 日历格内任务、日历右侧 TODO 栏、当日 TODO 的菜单新增“复制到明天”和“移动到未来TODO”。Android 日历格点按任务可打开操作菜单，长按仍用于拖动。
- “复制到明天”以原任务所属日期的下一天为目标，保留原任务，创建一条独立的未完成任务；内容、备注、分类、标签、优先级保留，执行时间与 DDL 各顺延一天，复制项不继承重复规则。
- “移动到未来TODO”保留任务 ID 和状态，从原日历移出；重复任务仅转移选中的那一次，不取消整组重复规则。
- 未来 TODO 纳入 JSON 备份、恢复和多端同步。全局搜索以“未来TODO”标识此类任务；使用日期范围时只搜索已安排日期的任务。

## 本地检查文件

- Windows：`dist/EchoDay-v1.0.8-dev.1-windows-x64-portable.zip`
- Android ARM64：`dist/android/EchoDay-v1.0.8-dev.1-android-arm64-v8a.apk`
- Android 通用版：`dist/android/EchoDay-v1.0.8-dev.1-android-universal.apk`

数据库升级至 Schema v5。测试同步时，主 PC 与客户端均需使用本检查版。旧备份中缺少未来任务标识的任务会继续保留在原日期。

## 手动检查建议

1. 在未来 TODO 新增两条任务，回日历检查循环滚动；完成或放弃一条后，确认它退出滚动栏。
2. 在未来 TODO 右键（Android 长按）转入当日 TODO，确认任务从未来列表消失并出现在今天。
3. 分别在日历格、右侧栏和当日 TODO 复制任务到明天，确认原任务仍在、复制项未完成、日期与时间正确。
4. 将普通任务和某一次重复任务移到未来 TODO，确认后续的重复任务继续存在。
5. 检查 JSON 导出恢复，以及双端同步后任务归属和状态是否一致。

# 丸成 / EchoDay — M5 设置、备份与视觉验收报告

日期：2026-09-05

## 1. 设置与主题

- 浅色、深色、跟随系统三种主题模式写入 `SettingsRepository`，重启后恢复。
- 提供 6 组克制的 INS 风主色；浅色主题使用所选主色，深色主题自动调整亮度与饱和度以保持可读性。
- 设置页新增日期格 TODO 预览条数（1～12）和默认任务排序；与日历和 TODO 列表共用原有设置键。
- 原有碎碎念、侧栏宽度、可见周数、顺延天数、色板和快捷键继续由同一设置仓库管理，因此统一进入备份。

## 2. JSON v1 备份格式

根对象包含：

- `formatVersion`：当前为 `1`。
- `exportedAt`：UTC ISO-8601 时间。
- `appVersion`：导出应用版本。
- `data`：分类、标签、重复任务组、TODO、TODO-标签关系和重复例外。
- `settings`：全部用户设置。

标准文件名为 `EchoDay-backup-yyyyMMdd-HHmmss.json`。法定节假日属于可重新获取的缓存数据，明确不进入备份。

## 3. 导入与恢复安全

- 预检阶段限制文件为 50 MB 以内，并校验 JSON 根结构、格式版本、必填类型、UTC 时间、日期、优先级、重复规则、修订号、ID 唯一性和外键引用。
- 合并导入按实体稳定 ID、设置键和 TODO-标签复合键去重；已有数据保留并计入跳过数。
- 覆盖恢复需在预检弹窗后再次确认。
- 覆盖前自动把当前数据导出到应用支持目录下的 `EchoDay/safety_backups`。
- 合并与覆盖的全部数据库写入均位于 Drift 事务中；任一插入失败会回滚整次导入。
- 导入结果显示导入数、跳过数；覆盖恢复额外显示安全备份路径。
- 设置页提供“清空数据”；确认后清除 TODO、分类、标签、重复规则及用户设置，保留节假日缓存，并在操作前自动生成 JSON 安全备份。

## 4. 平台边界

- 文件交互使用 `file_selector`，应用私有目录使用 `path_provider`。
- `BackupRepository` 继续只暴露路径和预检/导入结果，不让页面依赖 Drift；Android 阶段可替换平台文件交互而不改变备份领域接口。

## 6. 手工体验清单

1. 在主题卡切换三种模式与不同主色，重启后确认保留。
2. 把日期格预览调到 1 和 12，观察日历密度；切换默认排序并打开不同日期。
3. 导出备份，确认文件名和成功提示。
4. 新增一项临时任务后，以“合并导入”导入旧备份，确认临时任务仍存在且重复项被跳过。
5. 再以“覆盖恢复”导入，确认出现二次确认、临时任务消失、备份数据恢复，并显示安全备份路径。
6. 选择非 JSON 或修改过的错误备份，确认预检失败且当前数据完全不变。

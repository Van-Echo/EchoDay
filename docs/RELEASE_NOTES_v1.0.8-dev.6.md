# V1.0.8-dev.6 本地修复预览

日期：2026/10/22。包含 dev.5 的全部功能；不发布 GitHub，不自动覆盖安装双端。

## 修复重新配对导致的冲突误报

- 合并引擎按实际字段值判断冲突，不再仅因两条操作并发就报错。
- 兼容旧版缺失的新字段默认值、JSON 字段顺序，以及自动创建/完成/放弃/删除时间在 SQLite 持久化后丢失的小数精度；计划执行时间、DDL 时间不进行秒级取整，真实任务内容、状态和未知字段差异不会被忽略。
- 保留严格的 operation ID 内容绑定、防重放、因果顺序及删除/编辑冲突规则。
- 双端升级后，读取冲突时自动审计旧记录，仅将可证明语义等价的误报标记为已处理；保留原记录作为审计，不批量覆盖 PC 或手机版本，不修改任务或操作日志。

## 重新配对入口

- 主 PC 的已连接设备卡片增加链条图标“重新配对”，弹出新的邀请二维码；在弹窗内核对设备码并批准。
- Android 与 Windows 客户端均增加“重新配对”：Android 可扫码，两端均可粘贴邀请。
- 保留原设备身份、密钥、任务、同步日志、游标、连接历史及默认配置，不重建全量基线。取消或错误主机不会删除原连接。
- 原密钥一致的已撤销设备只有经过主 PC 再次批准后才能恢复；错误密钥、不同主机身份不会自动替换。卸载导致身份丢失时仍使用“配对新设备”。
- 主机设备操作区改为可换行布局，避免新增按钮挤压设备名称。

## 本次实际数据修复

在完整 SQLite 备份的副本上先演练，再退出 PC 应用、重新备份并处理实际数据库：567 项误报全部标记为已处理，剩余未解决 0 项；173 条任务、1454 条操作和其他 16 张表的数据哈希保持不变，完整性检查通过。未清空或重建数据，未改动 Android 私有数据库。

手机需要升级到此版本，才能以同一规则自动核算并清除其本地误报。双端均建议升级，避免旧客户端继续显示旧判断结果。无需删除设备、清空数据或再次配对来消除误报。

## 验证结果

- 完整回归 265 项通过，2 项按配置跳过；格式检查及静态分析通过。

- 实际 PC 数据库先备份演练再处理，16 张非冲突表的全量行哈希未变化，SQLite 完整性检查通过。Android 私有数据未被工具直接修改，新版本会在应用内执行相同的审计规则。

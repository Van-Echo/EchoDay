# Android Data Safety 填写基线

适用版本：EchoDay V1.0.1 正式版（2026-09-09）

本文件用于填写应用商店表单，最终提交前仍需按当时商店定义复核。

## Google Play Data Safety 建议答案

- 应用是否由开发者收集或与第三方共享必填用户数据类型：当前实现没有开发者后台、分析或广告数据流；最终答案仍须按发布时 Google Play 对“用户设备间直接同步”的定义复核。
- 数据是否经过传输：用户启用同步后，任务数据会通过 TLS 发送到用户指定且已配对的主 PC；不会发送到 EchoDay 项目方服务器。
- 是否允许用户请求删除数据：应用内提供“清空数据”；也可通过系统清除数据或卸载。
- 是否有账号创建：否。
- 是否含广告：否。
- 是否面向儿童：当前不作为儿童专用应用发布。

## 数据流说明

| 场景 | 数据 | 目的地 | 是否由用户触发 |
| --- | --- | --- | --- |
| 日常使用 | TODO、分类、标签、设置 | 设备应用私有目录 | 是 |
| JSON 导出 | 用户数据副本 | 用户通过系统文件选择器指定的位置 | 是 |
| JSON 导入 | 用户选择的备份文件 | 设备应用私有目录 | 是 |
| 节假日更新 | 请求年份、公开节假日响应 | `sousuo.www.gov.cn` | 是 |
| 多端同步 | TODO、分类、标签、重复规则和同步元数据 | 用户指定的主 PC 及已配对设备 | 是，需先启用并配对 |
| 扫码配对 | 二维码图像仅在设备上解析 | 不上传 | 是 |
| 关于页外链 | 目标网址 | 系统浏览器 | 是 |

## Android 权限

- `android.permission.INTERNET`：用于用户主动更新中国法定节假日数据，以及连接用户自己的局域网或 Tailscale 同步主机。
- `android.permission.CAMERA`：仅在用户主动进入二维码扫描页面时申请，用于本机识别 EchoDay 配对码。
- 不申请通讯录、定位、麦克风、通知、系统日历或“管理所有文件”权限。
- 文件备份通过 Storage Access Framework / 系统文件选择器完成。

## 每次发布前复核

- 检查依赖中是否新增分析、崩溃上报、广告、账号或云服务 SDK。
- 检查 AndroidManifest 合并结果是否新增权限。
- 检查节假日数据源和关于页链接是否变化。
- 复核设备直连同步、TLS、二维码扫码和 Tailscale 在当时 Google Play Data Safety 表单中的归类。
- 若未来加入开发者托管云同步、提醒、崩溃上报或账号，先更新隐私政策和商店表单，再发布功能。

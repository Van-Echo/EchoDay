# Android Data Safety 填写基线

适用版本：EchoDay v0.1.0（2026-09-08）

本文件用于填写应用商店表单，最终提交前仍需按当时商店定义复核。

## Google Play Data Safety 建议答案

- 应用是否收集或共享任何必填用户数据类型：否。
- 数据是否经过传输：应用没有向开发者后台传输用户内容的流程，因此不适用。
- 是否允许用户请求删除数据：应用内提供“清空数据”；也可通过系统清除数据或卸载。
- 是否有账号创建：否。
- 是否含广告：否。
- 是否面向儿童：当前不作为儿童专用应用发布。

## 数据流说明

| 场景 | 数据 | 目的地 | 是否由用户触发 |
| --- | --- | --- | --- |
| 日常使用 | TODO、分类、标签、设置 | 设备应用私有目录 | 是 |
| JSON 导出 | 用户数据副本 | 用户通过系统文件选择器指定的位置 | 是 |
| JSON 导入 | 用户选择的备份文件 | 设备应用私有目录 | 是 |
| 节假日更新 | 请求年份、公开节假日响应 | `sousuo.www.gov.cn` | 是 |
| 关于页外链 | 目标网址 | 系统浏览器 | 是 |

## Android 权限

- `android.permission.INTERNET`：仅用于用户主动更新中国法定节假日数据，以及外部网页打开流程所需的系统能力。
- 不申请通讯录、定位、相机、麦克风、通知、日历或“管理所有文件”权限。
- 文件备份通过 Storage Access Framework / 系统文件选择器完成。

## 每次发布前复核

- 检查依赖中是否新增分析、崩溃上报、广告、账号或云服务 SDK。
- 检查 AndroidManifest 合并结果是否新增权限。
- 检查节假日数据源和关于页链接是否变化。
- 若未来加入云同步、提醒、崩溃上报或账号，先更新隐私政策和商店表单，再发布功能。

# EchoDay V1.0.8 发布说明

发布日期：2026-10-22

## 未来 TODO 与日常规划

- Windows、Android 新增“未来TODO”，收纳尚未安排日期的事项，支持新增、编辑及转移到当日TODO。
- 日历与当日任务菜单新增“复制到下一天”和“移动到未来TODO”。复制以任务所属日期为基准，保留原任务，便于复盘。
- Windows 日历在碎碎念下方居中轮播未完成的未来TODO；设置中可调整间隔（1～3600 秒，默认 4 秒）及是否显示编号。窗口失去焦点但仍可见时继续播放，最小化或完全遮挡时暂停；Android 不显示滚动栏。
- 白底应用图标改为圆角，保留应用内部透明底 Logo。

## 多端同步与配对

- 主 PC 监听接口改为已保存列表，可从系统发现的接口中新增，新增后立即切换；支持设置默认接口。
- 首次配对二维码携带监听地址与端口，主 PC 在配对弹窗内显示设备码和确认操作，批准成功后自动关闭。
- 新增“更新 WLAN”二维码，已配对手机扫码即可验证并保存新地址，无需删除设备或反复手输。Windows 客户端支持粘贴更新连接码。
- 双端客户端支持保存多个主机地址、切换连接及设置默认项。地址更新仍验证原同步组、主机身份、证书指纹和设备认证；失败时保留原配置及本地任务。
- 已连接设备支持“重新配对”，保留设备身份、任务、操作日志和同步游标，避免重新生成全量基线。同密钥的已撤销设备仍需主 PC 再次确认。
- 设备显示名称与四个操作按钮同一行显示；修改备注直接替换标题中的原设备名，清空可恢复。原始设备身份不变，主机名更新不会覆盖用户命名。

## 修复与数据兼容

- 修复重新配对或重装后，相同字段值被误判为大量同步冲突的问题；兼容旧字段默认值和数据库自动时间戳精度，保留真正的内容、计划时间、状态及删除/编辑冲突。
- 双端升级后自动核查历史冲突，只消除可以验证为相同数据的误报，不批量覆盖任务，保留冲突审计记录。
- 数据库升级至 Schema v5，新增未来TODO标记；迁移兼容曾被旧版降低版本标记、但已有新字段的数据库，避免重复建列导致启动或服务不可用。

## 下载与升级

- Windows 10/11 x64：`EchoDay-v1.0.8-windows-x64-portable.zip`
- 大多数现代 Android 手机：`EchoDay-v1.0.8-android-arm64-v8a.apk`
- 其他 Android 设备：`EchoDay-v1.0.8-android-universal.apk`
- 同时提供 SHA-256 校验文件；安装包不包含开发者任务、数据库、备份或配对密钥。

Windows 解压全部文件后即可运行；Android 无需 Google Play 服务。建议先导出 JSON 备份，再将同步组内主 PC 与所有客户端一起覆盖升级。Android 继续使用相同签名、相同 APK 类型更新，无需卸载；修复冲突不需要清空任务、删除设备或重新配对。

Schema v5 数据库升级后不要再与旧版本交替打开同一份数据。校园网仍需允许设备互相访问，扫码不能绕过网络隔离或防火墙；无法直连时可使用自己的 Tailscale 网络。

- 正式版本代码生成、格式检查、静态分析通过；完整自动化回归 265 项通过，2 项按配置跳过。原生窗口可见性测试通过；Windows 和 Android 发布包重新构建。
- 覆盖真实 HTTPS 双数据库同步、重新配对身份校验、历史误报审计、真实冲突保留、接口及默认连接持久化和设备列表布局；开发预览已完成用户手动验收。

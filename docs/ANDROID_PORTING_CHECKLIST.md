# EchoDay Android 后续适配清单

M6 不实现 Android 发布；本清单记录从当前共用 Flutter 工程进入移动端阶段时的差异。

## 已可复用

- TODO、分类、标签、重复规则、排序、顺延、搜索和备份领域模型。
- Drift schema v2、Repository 接口、UUID、UTC 时间与软删除策略。
- Riverpod 状态管理、路由、本地化、主题、节假日与节气服务。
- Android 自适应图标资源及“成”品牌分配。

## 必须适配

- 把桌面侧栏、鼠标右键、双击、拖动分隔线改为触控导航、长按菜单和移动端详情页。
- 为窄屏重新确定连续周日历密度、日期格预览上限、编辑器和全屏 TODO 布局。
- Windows 全局热键不可复用；设计 Android 桌面快捷方式、通知入口或系统级替代方案。
- `file_selector` 在 Android 的保存位置能力与 Windows 不同，需要以系统分享/文档创建流程完成导出。
- 验证 Android 分区存储、备份文件权限、应用支持目录和卸载数据语义。
- 配置发布签名、包名、版本码、隐私声明、目标 SDK 和商店素材。
- 在真实 Android 设备验证时区、夏令时、中文输入法、返回手势、深色模式和进程恢复。

## 后续可选

- 通知、闹钟与后台提醒。
- 账号与云同步实现，继续依赖现有 Repository/同步预留字段。
- 小组件、分享目标、快捷新增和第三方日历导入。

# 丸成 / EchoDay v0.1.0 Android

发布日期：2026-09-08  
平台：Android 7.0（API 24）及以上，ARM64 为主要支持架构

## 首个 Android 候选版本

- 移动端连续周日历默认显示两周，下半屏用于所选日期的 TODO 列表。
- 选中日期可用 3 列 × 2 行的焦点卡片展示更多任务，点击可收起或再次展开；“设置 → 日历与任务”可决定启动时是否默认放大今天，默认关闭。
- 支持 TODO 新增、编辑、删除、完成、恢复、排序、顺延和跨日期拖动。
- 支持计划执行时间、计划 DDL、逾期状态、优先级、备注、分类、标签和重复规则。
- 支持全局搜索、中国法定节假日/调休、二十四节气及手动联网更新。
- 支持中文 / English、深浅主题、横竖屏、系统字体缩放和沉浸式全屏。
- Android 日历格 TODO 字号可从 5 px 起调节；双时间在小屏中纵向排列。
- 焦点卡片日期按“月份 日期”排列；颜色选择器支持 HSV、十六进制和 RGB 输入，时间选择器采用左侧时/分下拉与右侧圆盘。
- 使用系统文件选择器导入和导出与 Windows 版兼容的版本化 JSON 备份。
- 不依赖 Google Play Services、GMS、Firebase、账号或云同步。

## 安装包选择

- 大多数现代手机优先使用 `EchoDay-v0.1.0-android-arm64-v8a.apk`。
- 不确定 CPU 架构时使用 `EchoDay-v0.1.0-android-universal.apk`。
- `.aab` 仅供应用商店上传，不能由用户直接安装。

## 已知限制

- 首版没有云同步、账号、系统通知、桌面小组件或系统日历同步。
- 早期测试包使用 Debug 签名，不能直接覆盖正式签名包；请先导出 JSON 备份，再卸载测试包并安装正式包。
- 部分 Android 系统会额外提示“允许安装未知来源应用”，这是直接安装 GitHub APK 时的系统安全流程。
- 法定节假日官网结构变化时，在线更新可能暂时失败；内置或已缓存数据仍可使用。

## 校验

下载后计算 APK 的 SHA-256，并与同版本 `.sha256` 文件中的对应行比较。Windows PowerShell 示例：

```powershell
Get-FileHash .\EchoDay-v0.1.0-android-arm64-v8a.apk -Algorithm SHA256
```

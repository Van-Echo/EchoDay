# 丸成 / EchoDay v0.1.0

发布日期：2026-09-05  
平台：Windows 10/11 x64 便携版

## 首个公开候选版本

- 以连续周日历为主体，固定 7 列并支持 5～10 周缩放和自适应高度。
- 支持单击选日、双击全屏 TODO、快速新增、完整编辑、完成/恢复、软删除、拖拽及多种排序。
- 支持计划执行时间、计划 DDL、逾期状态、优先级、备注、分类、标签、自定义色板和任务顺延。
- 支持重复任务、单次例外、“仅本次”和“本次及之后”。
- 支持内容、备注、分类、标签的全局搜索及组合筛选。
- 内置 2025、2026 年中国法定节假日/调休数据，支持政府网站手动更新和二十四节气计算。
- 支持浅色、深色、跟随系统、主色、快捷键和日历碎碎念设置。
- 支持版本化 JSON 导出、预检、合并导入、覆盖恢复和清空数据；覆盖或清空前自动创建安全备份。
- Windows 任务栏和原生标题栏采用白底“丸”多尺寸图标；应用内容区继续平均使用透明底“丸”“成”双标识。
- 便携包不含用户数据库或备份文件，并内置应用本地 Visual C++ 运行库；无需安装 Flutter、Visual Studio 或 C++ 开发组件。

## 数据库升级

- 数据库 schema 从 v1 升至 v2。
- 新增活动任务日期/完成状态复合索引。
- v1→v2 会原样保留任务、设置和其他用户数据。

## 已知限制

- 当前只交付 Windows x64 便携版，不提供安装器、自动更新或代码签名。
- 未启用账号、云同步、提醒通知和第三方日历同步。
- Android 工程入口已保留，但本版本未完成 Android UI/权限/发布验收。
- 法定节假日官网结构变化时，在线更新可能暂时失败；已缓存或内置的数据仍可使用。
- 普通搜索已针对 10,000 条本地任务验证；尚未启用 SQLite FTS5。

## 校验

下载后可在 PowerShell 中运行：

```powershell
Get-FileHash .\EchoDay-v0.1.0-windows-x64-portable.zip -Algorithm SHA256
```

结果应与同目录 `.sha256` 文件一致。

## 校园网排查记录

两台设备实际连接 TJ-WIFI。排查时，正在运行的 V1.0.7 主 PC 服务仅监听 Tailscale 地址；手机到此监听端口 TCP 探测成功。手机到 PC 校园网地址的同端口超时，但服务没有监听该地址，因此此结果不能证明校园网存在客户端隔离。实际设备地址不随公开文档发布。

进一步检查手机设置，保存的主机端口与当前主机实际监听端口不一致。这是本次手机仍显示不可达的直接原因。升级后可在手机“设置 → 多端同步”将端口改为主 PC 显示的端口，点击保存并重试，无需删除配对。

同一 SSID 不保证设备可互访。在校园网中建议两端保持 Tailscale 在线，并选择 Tailscale 监听接口；不要将校园网 Wi-Fi 的 `100.x` 地址误认为 Tailscale 地址。此处验证的是网络端口连通性，不代表已经完成数据同步。

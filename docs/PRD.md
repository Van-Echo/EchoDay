# 丸成 / EchoDay — Windows MVP 产品需求文档

> 状态：需求基线 v0.1  
> 日期：2026-09-02  
> 产品署名：丸一口 / Van Echo

## 1. 产品定位

丸成（EchoDay）是一款以日历为主体的个人工作与生活规划应用。用户通过月历快速查看每天的待办摘要，在日历主页或独立的当日 TODO 页面中创建、编辑、完成、恢复与删除任务。

第一阶段交付 Windows 桌面端 MVP，采用离线优先模式；后续扩展 Android 和云同步时复用领域模型、数据仓库接口与主要页面结构。

## 2. MVP 目标与非目标

### 2.1 目标

- 提供清晰、轻量、可直接操作的月历工作台。
- 支持完整的个人 TODO 生命周期与重复任务。
- 数据本地持久化，并支持版本化 JSON 备份和恢复。
- 支持中国法定节假日、调休标记与二十四节气。
- 采用简约 INS 风格，支持浅色、深色和跟随系统主题。
- 在架构和数据模型中预留 Android 与云同步扩展点。

### 2.2 第一阶段非目标

- 用户账号、联网云同步与多设备冲突解决 UI。
- Android 安装包。
- 系统通知和提醒推送；有 DDL 的未完成任务仅在应用内标记逾期。
- 团队协作、任务指派或共享日历。
- Google Calendar、Outlook 等第三方日历同步。
- 完整农历日期展示。

## 3. 核心术语

- **所属日期**：任务在日历中归属和展示的日期。
- **计划执行时间**：用户计划开始或执行任务的日期时间，可为空。
- **计划 DDL 时间**：任务最迟应完成的日期时间，可为空且可跨越所属日期。
- **逾期**：任务未完成、存在计划 DDL 时间，且当前时间已超过 DDL。
- **分类**：每个任务最多属于一个分类。
- **标签**：每个任务可拥有多个标签。

## 4. 页面与导航

### 4.1 启动与主页面

- 启动页或“关于”页同时展示“丸成 / EchoDay”和“丸一口 / Van Echo”。
- 主页面由顶部工具栏、月历主体、右侧 TODO 侧边栏与“回到今天”按钮组成。
- 顶部工具栏包含品牌、上月、下月、当前年月、全局搜索、主题切换和设置入口。

### 4.2 响应式结构

- 宽窗口采用“月历 + 可调宽 TODO 侧边栏”双栏布局。侧边栏默认且最小占双栏可用宽度的 12.5%，最大占 50%；比例计算不含分隔线本身。
- 两栏之间提供可拖拽分隔线；鼠标悬停时显示左右调整光标，拖动时实时更新两栏宽度。
- 分隔线支持键盘操作：左右方向键以小步长调整，Home 回到 12.5%，End 调至 50%；双击分隔线恢复 12.5%。
- 调整结果作为用户设置持久化；改变窗口宽度时保持比例，进入窄窗口单栏后暂时隐藏分隔线和侧边栏，恢复双栏时还原原比例。
- 窄窗口自动隐藏侧边栏，切换为单栏布局。
- Android 阶段沿用单栏与独立当日详情页面。
- 日历横向始终只有周一至周日 7 列；屏幕变宽时增大日期格宽度，不横向增加月份或星期列。
- 日历纵向采用跨月份连续周流，不受单个月份边界限制。
- 2560×1440 与 3840×2160 纳入正式适配和测试矩阵；高分辨率用于提供更宽、更高的日期格及更多 TODO 预览空间。
- 上月/下月按钮移动连续周流的时间锚点；“回到今天”将今天所在周重新定位到可视区域。

### 4.3 日期交互

- 单击日期：跳转并选中该日，刷新右侧 TODO 侧边栏。
- 双击日期：将该日 TODO 列表放大为占据整个应用窗口的全屏专注模式。
- 右侧栏同时提供明确的“全屏打开”按钮，避免功能只能通过双击发现。
- 全屏 TODO 模式支持 Esc 或“返回月历”按钮退出，并恢复原来的周流位置、可见周数和选中日期。
- 日期格内提供轻量 `+` 入口，用于快速新增任务。
- “回到今天”使用右下角悬浮按钮；点击后切回今天并确保今天可见。

## 5. 自适应月历

- 每周从周一开始，星期标题固定在顶部。
- 每行始终展示 7 个日期格。
- 日期按周纵向连续排列，跨月时不中断、不另起横向月面板；每月 1 日的日期格使用覆盖大部分格子的中文月份数字水印，仅显示“一”“二”“十一”等，不显示“月”，并与左上角的日期数字 `1` 完全分离。
- 首次启动默认显示 5 个完整星期，5 行日期格均分星期标题以下的全部可用高度，恰好铺满页面。
- 高度基准是当前应用窗口的实际内容区逻辑高度：先扣除应用工具栏、日历状态栏、星期标题和必要内边距，再把剩余空间全部交给日期网格；不得使用按分辨率预设的固定像素高度。
- 应用全屏/最大化时使用全部可用屏幕内容高度；窗口化时跟随当前窗口高度实时重算，避免内容超出窗口或只占据部分窗口。
- 用户按住 Ctrl 并滚动鼠标滚轮可改变日期格高度：向下滚动缩小日期格并增加可见周数，向上滚动放大日期格并减少可见周数。
- 可见周数只允许 5～10 个整数档位，最少 5 周、最多 10 周。
- 普通鼠标滚轮不缩放，负责沿连续时间线按周上下浏览。
- 工具栏显示当前可见周数，并提供“显示更少周/显示更多周”按钮作为可发现、可访问的替代操作。
- 用户调整后的可见周数持久化；“恢复默认视图”或首次启动使用 5 周。
- 日期格默认预览最多 6 条 TODO，用户可在设置中调整为 1～12 条。
- 超出当前预览上限时显示“还有 N 项”，点击进入当日详情。
- 日期格高度由“日历可用高度 ÷ 当前可见周数”计算；窗口高度变化时保持周数不变并重新均分高度。
- 日期格实际可展示的 TODO 条数取“用户预览上限”和“当前格子物理可容纳条数”的较小值。
- Ctrl+滚轮缩放时尽量保持当前视图中心周不移动，避免时间位置跳跃。
- “上月/下月”按钮始终直接切换相邻月份。
- 打开或返回主页面时，优先定位到所选日期所在周；无选中日期时定位到今天。
- 调整窗口尺寸、可见周数或预览条数后，当前选中日期必须仍在可视区域。
- 若当前物理空间不足以显示用户设置的条数，实际显示可容纳条数，并以“还有 N 项”收尾，不允许布局溢出。

### 5.1 目标分辨率与缩放

- 基础验证：1280×720、1920×1080 和窄窗口。
- 高分辨率验证：2560×1440、3840×2160。
- Windows 显示缩放至少覆盖 100%、125%、150% 和 200% 的代表性组合。
- 所有分辨率和显示缩放下始终保持 7 列；默认 5 行与用户选择的 6～10 行都必须准确铺满日历可用高度。
- 2K/4K 在同样显示 5 周时，日期格会更高并容纳更多 TODO 内容，而不是增加横向月份数量。

## 6. TODO 功能

### 6.1 用户字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 内容 | 是 | TODO 标题，去除首尾空格后不可为空 |
| 所属日期 | 是 | 日历归属日期 |
| 是否完成 | 是 | 默认否，可切换恢复 |
| 创建时间 | 自动 | 创建时生成，不由用户编辑 |
| 计划执行时间 | 否 | 可包含日期和具体时间 |
| 优先级 | 是 | 高、中、低、无；默认无 |
| 分类 | 否 | 单分类，支持自定义名称与颜色 |
| 标签 | 否 | 多标签，支持自定义名称与颜色 |
| 备注 | 否 | 补充说明 |
| 计划 DDL 时间 | 否 | 可跨越所属日期 |
| 重复规则 | 否 | 见 6.5 |

内部另存 UUID、更新时间、完成时间、删除标记和手动顺序等同步与排序字段。

### 6.2 新增与编辑

- 日历日期格、右侧栏和当日详情页均可新增任务。
- 快速新增只要求内容；按 Enter 完成创建。
- “更多”展开优先级、时间、分类、标签、备注和重复规则。
- 完整编辑在桌面端采用右侧抽屉，避免完全遮挡日历。
- 数据编辑后自动保存。

### 6.3 完成与恢复

- 点击复选框完成任务，再次点击恢复为未完成。
- 已完成任务显示删除线并淡化，统一移动至列表底部。
- 已完成区域默认折叠，可手动展开。
- 恢复任务后重新进入未完成区域并按当前规则排序。
- 右侧 TODO 栏与全屏当日页提供“未完成任务顺延至下一天”按钮；确认后只移动所选日期的未完成项，已完成项留在原日。
- 顺延时，所属日期、计划执行时间和计划 DDL 时间同步向后移动一个本地日历日并保留钟点；重复任务只实体化并移动当前发生项，不修改整组规则。

### 6.4 删除

- 普通任务删除后显示短暂的“撤销”入口，不弹确认框。
- 重复任务删除时询问作用范围：“仅本次”或“本次及之后”。
- 内部采用软删除字段，为撤销和未来云同步保留依据。

### 6.5 重复规则

第一版支持：

- 每天。
- 每个工作日。
- 每周，可选择星期几。
- 每月，可选择日期。
- 自定义间隔，例如每 3 天或每 2 周。
- 可选结束日期或重复次数。

每个发生项可独立完成。编辑重复任务时允许“仅本次”或“本次及之后”。“工作日”依据已知中国节假日与调休数据判断；目标年份数据尚未发布时，暂按周一至周五判断，并在界面提示数据覆盖状态。

## 7. 排序

提供以下模式，并记住用户上次选择：

- 手动排序：支持拖拽并持久化自定义顺序。
- 创建时间：支持升序或降序。
- 计划时间：按计划执行时间或计划 DDL 时间排序。
- 优先级：高 → 中 → 低 → 无。
- 综合排序：默认模式。

综合排序固定规则：

1. 未完成在前，已完成在后。
2. 优先级：高 → 中 → 低 → 无。
3. 同优先级先按计划执行时间升序。
4. 无计划执行时间时，按计划 DDL 时间升序。
5. 两者都没有时，按创建时间升序（早创建在前）。
6. 同时存在执行时间和 DDL 时，执行时间为主，DDL 为下一层比较条件。

只有手动排序模式允许拖拽，避免自动排序与手动位置冲突。

## 8. 全局搜索

- 搜索范围：TODO 内容、备注、分类和标签。
- 支持按完成状态、日期范围、分类和标签筛选。
- 结果展示所属日期、完成状态、优先级、计划执行时间和计划 DDL 时间。
- 点击搜索结果后定位到对应日期和任务。

## 9. 中国日历信息

- 显示中国法定节假日名称、法定休息日和调休“班/休”标记。
- 显示二十四节气，不显示完整农历。
- 节气本地计算，不依赖联网。
- 节假日采用“内置年度 JSON + 本地缓存 + 可替换远端数据源”。
- 设置页提供数据覆盖年份、来源、版本和“检查更新”。
- 尚未发布年度安排时明确提示，不自行推测调休。
- 更新失败或校验失败时继续使用最近一次有效数据。

节假日安排的具体连休与调休会按年度通知发布；基础办法本身也可能修订。产品数据以中国政府网公布内容为核验基准。

## 10. 备份与恢复

- 导出单一、带格式版本号的 JSON 文件。
- 默认文件名：`EchoDay_Backup_YYYY-MM-DD_HHmm.json`。
- 备份包含 TODO、分类、标签、重复规则与用户设置。
- 节假日缓存不进入用户备份。
- 合并导入为默认方式，通过 UUID 去重并按更新时间处理同一记录。
- 覆盖恢复需要二次确认，执行前自动生成临时安全备份。
- 导入前验证格式版本、必填字段、字段类型与引用关系；失败不得破坏当前数据库。

## 11. 视觉与可用性

- 风格：简约 INS、充足留白、轻微圆角、低饱和柔和主色，不过度可爱。
- 初始配色方向：暖白 + 鼠尾草绿；深色主题使用炭灰底色。
- 支持浅色、深色和跟随系统。
- 完成任务淡化并使用删除线；逾期任务采用克制红色文字或细边提示。
- 中文优先系统微软雅黑，英文采用 Flutter 默认现代无衬线字体。
- 所有主要操作支持键盘焦点；快速新增支持 Enter。
- 不仅依赖颜色表达完成、逾期和优先级状态。

## 12. 设置与关于

- 外观：主题模式、主色。
- 日历：日期格预览条数、默认排序方式。
- 数据：导出备份、合并导入、覆盖恢复。
- 节假日：数据年份、来源与检查更新。
- 关于：丸成 / EchoDay、丸一口 / Van Echo、版本信息。

## 13. 验收标准

- 重启应用后所有任务、设置、顺序和完成状态保持一致。
- 可从月历、侧边栏和当日详情完成核心 CRUD。
- 完成任务立即淡化、加删除线并移动到底部，恢复后正确归位。
- 五种排序模式结果稳定，综合排序符合第 7 节规则。
- 重复任务的单次完成不影响其他发生项。
- 逾期判定在应用启动、任务更新和日期跨越后正确刷新。
- 首次启动默认显示 5 个完整星期并精确填满日历高度；Ctrl+滚轮可在 5～10 周间逐级缩放且无溢出。
- 普通滚轮按周浏览连续日期；跨月时周流不中断，月份标记和顶部时间范围正确更新。
- 1280×720、1920×1080、2560×1440、3840×2160 均保持 7 列，并在当前可见周数下正确均分日期格高度。
- 最大化、还原和拖拽改变窗口高度时，日期网格实时占满剩余内容区，不出现底部大块空白或超出窗口。
- 单击任意可见日期会更新所选日期和侧边栏；双击会打开全屏当日 TODO，退出后保持原周流位置、周数和选择状态。
- 搜索可命中标题、备注、分类和标签，并能定位原任务。
- 离线时仍可使用全部 TODO 功能和已内置年份的节假日数据。
- JSON 导出后可在空数据库中完整恢复；无效文件不会修改现有数据。
- 浅色、深色与跟随系统主题均可正常切换并持久化。
- 月历与 TODO 栏之间的分隔线可通过鼠标和键盘调节，TODO 栏严格限制在 12.5%～50%，窗口缩放及重启后保持用户比例。

## 14. 待视觉原型验证

- 主色具体色值与品牌字标样式。
- 日期格信息密度、任务行高度和不同窗口尺寸下的可读性。
- 右侧抽屉与固定侧边栏同时出现时的宽度和层级。
- 搜索入口采用展开式搜索框还是独立搜索页。

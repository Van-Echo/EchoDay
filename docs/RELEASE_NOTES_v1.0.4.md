# EchoDay V1.0.4 发布说明

EchoDay V1.0.4 为 Android 日历格焦点放大功能增加独立总开关，让小屏日历可以按个人使用习惯保持紧凑。

## 更新内容

- 在 Android“设置 → 日历与任务”中新增“启用日历格放大”开关。
- 日历格放大功能默认关闭；关闭时，点击日期只会选中日期，不再显示 3 列 × 2 行的焦点卡片。
- 保留“默认放大当日日历格”选项，并在总开关关闭时自动置灰，避免设置含义冲突。
- 开启总开关后，可继续使用点击放大、点击焦点卡片收起和默认放大今天等原有交互。
- 补充中英文界面文案及自动化测试。

## 下载

- Windows 10/11 x64：`EchoDay-v1.0.4-windows-x64-portable.zip`
- 大多数现代 Android 手机：`EchoDay-v1.0.4-android-arm64-v8a.apk`
- 其他 Android 设备：`EchoDay-v1.0.4-android-universal.apk`
- 应用商店发布：`EchoDay-v1.0.4-android.aab`

Android Release APK 使用 EchoDay 正式签名，可覆盖安装同签名的既有正式版本并保留本地数据。升级前仍建议按需导出 JSON 备份。

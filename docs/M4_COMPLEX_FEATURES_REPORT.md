# 丸成 / EchoDay — M4 复杂能力验收报告

> 日期：2026-09-04  
> 状态：实现与自动化验收完成，等待体验验收

## 已实现

- 重复任务支持每天、工作日、每周多选、每月和自定义天/周/月间隔，并支持结束日期或重复次数。
- 重复规则按需展开虚拟发生项；仅当发生项被完成、编辑、删除或手动排序时才实体化，避免无限预生成。
- 重复任务支持“仅本次”和“本次及之后”；后者会截断旧规则并从所选日期建立新版本，历史记录保持不变。
- 右侧栏和全屏当日页提供“未完成任务顺延至下一天”：经确认后移动全部未完成项，执行时间与 DDL 保留钟点并顺延一个本地日历日；完成项不动，重复任务仅移动当前发生项。
- 全局搜索覆盖内容、备注、分类和标签，支持完成状态、日期范围、分类和多标签筛选。
- 搜索结果展示日期、优先级、计划执行时间、计划 DDL、分类和标签；点击后进入对应日期并自动打开任务编辑器。
- 日期格显示中国法定节假日、调休“休/班”及二十四节气；信息行固定占位，不破坏日期格高度自适应。
- 内置 2025、2026 年国务院办公厅官方安排；年度 JSON 具备 schema、来源、版本和 SHA-256 完整性校验。
- 设置页提供年份选择和“检查更新”按钮：先读取本地数据库，再查询国务院政策文件库并抓取 `www.gov.cn` 正文；解析成功后校验并写入数据库。
- 官网不可用但本地有数据时继续使用数据库并提示；两者均无有效数据时明确报错；缺失年度不猜测调休，工作日重复回退周一至周五。
- 二十四节气使用太阳黄经本地求解，不依赖联网。

## 数据来源与安全边界

- 节假日基准：中国政府网国务院办公厅年度通知。
- 官网发现入口：`https://sousuo.www.gov.cn/search-gov/data`。
- 只接受 HTTPS 且主机为 `www.gov.cn`/`gov.cn` 的正文候选。
- 必须同时匹配标题年份、发布机关、发文字号、七类法定节日段落、放假天数与有效日期范围。
- 抓取或校验失败不会覆盖已验证缓存。
- 节气日期回归基准：香港天文台《2026 年公历与农历日期对照表》。

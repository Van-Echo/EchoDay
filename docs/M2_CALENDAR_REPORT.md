## 已实现

- 周一开头、跨月份连续且固定 7 列的日期网格。
- 默认 5 周均分全部剩余高度；窗口尺寸变化时实时重算，无固定分辨率高度表。
- 普通滚轮按周浏览，Ctrl+滚轮在 5～10 周间缩放，并提供可见的增减周按钮。
- 上月、下月、当前可见月份范围与“回到今天”悬浮按钮。
- 单击日期更新右侧栏；双击日期或侧栏按钮进入全屏当日 TODO，返回后保留日期和周流状态。
- 日期格 TODO 摘要、物理容量限制、“还有 N 项”和快速新增。
- 月首格使用独立的“一”“二”“十一”等中文月份数字水印。
- TODO 侧栏支持 12.5%～50% 拖拽、键盘调整、双击复位和数据库持久化。
- 窄窗口自动隐藏侧栏；恢复宽窗口后继续使用保存的比例。
- Drift 数据库和 Repository 已装配到应用，不在 Widget 内直接访问 SQLite。
- Windows 集成测试结束后自动重建普通应用，避免测试入口覆盖可双击的 EXE。
- Windows 原生标题改用 Unicode 转义，当前正确显示“丸成 EchoDay”。

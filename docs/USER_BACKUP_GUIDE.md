# 丸成 / EchoDay 数据备份与恢复指南

## 手动导出

1. 打开“设置 → 数据备份与恢复”。
2. 点击“导出 JSON 备份”。
3. 选择保存位置。默认文件名形如 `EchoDay-backup-20260905-123456.json`。
4. 把备份复制到另一个磁盘或可信的个人存储位置。

备份包含 TODO、分类、标签、重复规则及可迁移的用户设置；中国法定节假日缓存不包含在内，恢复后可在设置中重新更新。默认备份目录、自动备份开关和保留数量属于设备本地设置，也不会写入 JSON。

## Windows 默认备份目录

Windows 版在“设置 → 数据备份与恢复”中提供“选择目录”“打开目录”和“测试写入”。未指定目录时，丸成使用应用支持目录下的 `EchoDay/Backups`；指定目录不可用时会回退到该默认位置，并在设置页提示。

“立即备份到默认目录”生成的文件位于 `Manual Backups` 子目录。开启“每日自动备份”后，丸成会在每天首次打开或回到前台时最多生成一份，保存在 `Automatic Backups` 子目录；用户可设置保留 1～30 份，超出部分从最早的自动备份开始清理。Android 仍使用系统文件选择器进行手动导入导出，不显示 Windows 目录设置。

## 合并导入

合并导入适合把另一份备份加入现有数据。丸成按稳定 ID 去重：当前已有的实体会保留并计入“跳过”，新实体会写入。整个操作在一个数据库事务中执行。

## 覆盖恢复

覆盖恢复会用备份内容替换当前 TODO、分类、标签、重复规则和可迁移的用户设置，但会保留本机的默认备份目录、自动备份开关与保留数量。选择覆盖后还需二次确认。执行前，丸成会把当前数据自动保存到默认备份目录的 `Safety Backups` 子目录；恢复失败时数据库事务会回滚。

## 便携版与用户数据库

Windows 版程序文件位于用户自行解压的目录，主数据库位于 Windows 用户“文档”目录中的 `echoday.sqlite`。因此：

- 更换或删除程序目录不会主动删除任务。
- 升级时可退出旧版，然后用新版程序目录启动；数据库会自动迁移。
- 删除用户数据库属于独立的数据清除操作，操作前应先导出 JSON。

## 清空数据

在“设置 → 数据备份与恢复”中选择“清空数据”，确认后会清除 TODO、分类、标签、重复规则和用户设置。操作前，丸成会在默认备份目录的 `Safety Backups` 子目录自动保存 JSON 安全备份；已下载的中国法定节假日缓存会保留。由于默认备份目录本身属于设备设置，清空后会恢复使用系统默认目录。

## 无法导入时

丸成会拒绝格式版本不兼容、字段类型错误、时间格式错误、ID 重复或引用关系损坏的文件，且不会修改当前数据。请保留原文件，并从另一份已知正常的备份恢复。

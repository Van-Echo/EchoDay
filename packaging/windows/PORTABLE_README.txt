丸成 | EchoDay v0.1.0 Windows x64 便携版

运行：解压全部文件后双击 EchoDay.exe。请勿只复制 exe，data 目录和 DLL 均为运行必需文件。
环境：无需安装 Flutter、Visual Studio 或 C++ 开发工具；Visual C++ 运行库已随包携带。
卸载：先退出丸成，再删除整个解压目录即可。
用户数据：数据库位于 Windows 用户“文档”目录中的 echoday.sqlite，不在程序目录内；删除便携版程序不会删除任务。
备份：建议在“设置 → 数据备份与恢复”中定期导出 JSON。覆盖恢复和“清空数据”前，丸成会自动创建安全备份。
系统：Windows 10/11 x64。
